# R Learning - Day 10

## Topic

Data Visualization Using Base R

## Concepts Covered

* `barplot()`
* `hist()`
* `boxplot()`
* `plot()`
* `rbind()`
* `cor()`
* Plot customization
* Scatter plots
* Data distribution

## Program Features

* Creates a student marks dataset
* Visualizes Biology marks using a bar plot
* Shows mark distribution using a histogram
* Displays the distribution using a boxplot
* Creates a scatter plot between Biology and Bioinformatics
* Compares marks across three subjects
* Calculates correlation between Biology and Bioinformatics

## Skills Learned

* Basic data visualization
* Understanding distributions
* Comparing variables
* Creating scatter plots
* Calculating correlations
* Interpreting relationships between variables

## Bioinformatics Relevance

Data visualization is an important part of bioinformatics analysis. Similar visualization techniques are used to explore gene expression, sequencing quality, sample distributions, and relationships between biological variables.
