# R Learning - Day 13

## Topic

Data Manipulation using dplyr

## Concepts Covered

- filter()
- select()
- arrange()
- mutate()
- summarise()
- group_by()
- slice()
- Pipe operator (%>%)

## Program Features

- Filters students based on Biology marks
- Selects specific columns
- Sorts students by marks
- Creates Total and Average columns
- Categorizes student performance
- Calculates average marks
- Groups students by performance
- Identifies the top-performing student
- Exports the processed dataset

## Skills Learned

- Data filtering
- Column selection
- Data sorting
- Creating new variables
- Grouped analysis
- Summary statistics
- Data export

## Bioinformatics Relevance

dplyr is widely used for manipulating biological datasets. It can be used to filter samples, select experimental variables, create derived measurements, summarize groups, and prepare datasets for downstream bioinformatics and statistical analysis.
