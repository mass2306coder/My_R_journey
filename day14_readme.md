# R Learning - Day 14

## Topic

Data Reshaping using tidyr

## Concepts Covered

- pivot_longer()
- pivot_wider()
- separate()
- unite()
- drop_na()

## Program Features

- Creates a wide-format student dataset
- Converts wide data into long format
- Converts long data back into wide format
- Separates combined information into columns
- Combines columns into a single variable
- Removes rows containing missing values
- Exports reshaped data as CSV

## Skills Learned

- Data reshaping
- Wide and long data formats
- Column separation
- Column combination
- Missing-data filtering
- Data export

## Bioinformatics Relevance

Data reshaping is frequently required when working with biological datasets.

For example, gene-expression data may initially contain samples as columns and genes as rows. Reshaping data into long or wide formats can make downstream statistical analysis and visualization easier.

These concepts are also useful when preparing RNA-seq, transcriptomics, and other omics datasets for analysis.
