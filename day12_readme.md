# R Learning - Day 12

## Topic

Handling Missing Data in R

## Concepts Covered

* `NA`
* `is.na()`
* `colSums()`
* `sum()`
* `complete.cases()`
* `na.rm = TRUE`
* Missing value replacement
* Data cleaning
* `write.csv()`

## Program Features

* Creates a dataset containing missing values
* Detects missing values
* Counts missing values by column
* Identifies incomplete rows
* Identifies complete rows
* Calculates means while ignoring missing values
* Replaces missing values with column means
* Verifies the cleaned dataset
* Saves the cleaned dataset as a CSV file

## Skills Learned

* Detecting missing data
* Quantifying missing data
* Cleaning datasets
* Handling `NA` values
* Exporting cleaned data

## Bioinformatics Relevance

Missing-value handling is an important step in biological data analysis. Real datasets may contain missing measurements, incomplete sample metadata, or missing experimental observations. Proper data cleaning helps prevent errors during downstream statistical and bioinformatics analyses.
