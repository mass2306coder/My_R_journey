# R Learning - Day 11

## Topic

Data Visualization with ggplot2

## Concepts Covered

* `ggplot()`
* `aes()`
* `geom_bar()`
* `geom_histogram()`
* `geom_boxplot()`
* `geom_point()`
* `geom_smooth()`
* `labs()`
* `facet_wrap()`

## Program Features

* Creates bar plots
* Visualizes data distributions
* Creates boxplots
* Creates scatter plots
* Adds regression trend lines
* Compares multiple subjects
* Uses faceting for separate visualizations

## Skills Learned

* Creating publication-style plots
* Mapping variables to visual properties
* Comparing groups
* Visualizing relationships between variables
* Understanding distributions

## Bioinformatics Relevance

ggplot2 is widely used for biological data visualization. Similar approaches can be used to create expression plots, sample-level visualizations, PCA plots, quality-control plots, and other research figures.
